# Linear Algebra I

Linear algebra is the language of machine learning. We study systems of
equations like $Ax = b$, where $A$ is a matrix encoding a linear map and
$x$, $b$ are vectors.

A foundational invariant is the determinant, which factors over eigenvalues:

$$\det(A) = \prod_i \lambda_i$$

Where this shows up in ML: every linear layer, every covariance matrix,
every change-of-basis in a normalizing flow.
